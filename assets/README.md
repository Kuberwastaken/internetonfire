# Assets

- `fonts/inter-latin-opsz-*.woff2`: Inter variable (weight + optical size), Latin subset, from `@fontsource-variable/inter@5.2.5`. SIL Open Font License, see `Inter-LICENSE.txt`.
- `this-is-fine.mp4` / `.webp`: see `THIS-IS-FINE.md`.
