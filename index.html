What belongs here, and what the labels mean
Confirmed
Primary evidence supports the description.
Reported
Attributed reporting; not independently established here.
Disputed
Sources materially disagree.
Needs evidence
A claim that has not been substantiated.

Publication dates drive the filters. Event dates are shown separately. An outage is not proof of a breach, and an X post is not proof of its claim. Inclusion does not imply AI caused an incident.

Corrections stay with each entry and in git history. No leaked records, credentials, or private messages. This is a public index, not an emergency alert service.

Got a source?

Add an incident or correct an existing one. Keep it short, dated, and sourced.

  1. Find the original report. Include the publication date and a vendor response if available.
  2. Edit the incident data in your fork and open a pull request. You can also open an issue.
  3. A maintainer checks the evidence. GitHub reactions help prioritise review; they never auto-merge.
