# Security

Do not put credentials, private victim records or working exploit payloads in issues or pull requests. This site indexes public incident evidence; it is not a leak mirror.

For an ordinary correction, use the incident form. For a site flaw, report the affected page and minimal reproduction without exposing users' information. If sensitive details are necessary, request a private reporting route first rather than posting them publicly.

Pull requests run with read-only repository permissions and do not deploy. Untrusted text is rendered with DOM text nodes, not injected HTML. Source links accept HTTPS only. GitHub's unauthenticated public API supplies the optional PR list; no token is shipped to the browser. The site does not collect submissions itself, run analytics, or store visitor searches.
